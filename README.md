Solmar Heat is an original top-down 2D open-world crime game set in the fictional city of Port Solana. Roam on foot or steal and drive cars, dodge traffic, take on a three-job story chain from fixer Carmen Vega, and manage your wanted level as police close in — with a live minimap, shops, a Pay 'n Spray, and localStorage saves. Built with vanilla JavaScript and canvas, no dependencies.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts   # build the hand-in into out/
npx serve out                          # or any static file server, then open the page
```

You can also open `game/index.html` directly in a browser.
